# Neshan_Scraping

## پروژه اسکرپینگ سایت نشان
درود و احترام عزیزان
با استفاده از این پروژه میتوانید داده های کسب و کارهای موجود در نشان را استخراج و در موقعیت های مناسب برای بازاریابی یا غیره استفاده کنید
راه اندازی اولیه بسیار ساده میباشد و دو ورودی را شما در ترمینال وارد میکنید .
ب عنوان مثال نام شهر و کافه 
فعلا 31 مرکز استان ایران در پروژه قرار داده شده است. چنانچه شهر شما خاص میباشد میتوانید شهر و مناطق خاص خود را اضافه نمایید.

## پیش‌نیازها
- Python 3.9 یا بالاتر
- کتابخانه selenium
- کتابخانه driver manager

## نکات نصب و راه اندازی اولیه

بعد از دانلود فایل ها با استفاده از پیپ کتابخانه های زیر را نصب کنید.

	```pip install webdriver-manager
	   pip install selenium
   
   
بعد از نصب پیشنیاز ها فایل neshan.py را اجرا کرده و برای مثال نام تهران را برای شهر نوشته و در ورودی دوم رستوران را وارد کنید.
داده ها ب شکل اتوماتیک در دیتابیس ذخیره خواهند شد.
امید است از پروژه نهایت استفاده را ببرید.
